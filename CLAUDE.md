# Instruções para Claude

Leia e cumpra integralmente [`AGENTS.md`](AGENTS.md) antes de analisar ou modificar este repositório. `AGENTS.md` é a política canônica para branches, commits, Pull Requests, staging, produção, banco de dados e segredos.

Nunca interprete “faça commit e push” como autorização para enviar diretamente à `main`, criar uma tag ou publicar em produção.
